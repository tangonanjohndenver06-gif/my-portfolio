# BSIT Personal Portfolio

## Files
- `index.html` — portfolio website
- `style.css` — website design and responsive layout
- `NumberGuessingGame.java` — sample Java console game

## How to view
Open `index.html` in a web browser.

## Before submitting
1. Replace the email and phone placeholders with your real contact details.
2. Confirm that the previous school name (OLSCHO) is spelled correctly and add any missing school details if needed.
3. Confirm whether Number Guessing Game is the same game as your CC102 final Performance Task. If not, replace the Java source and the displayed code in `index.html` with your actual game.
4. Create a public GitHub repository and upload all files while keeping the folder structure.
5. Enable GitHub Pages if you also want a live website link.

## GitHub upload
Create a new public repository on GitHub. Upload `index.html`, `style.css`, `NumberGuessingGame.java`, and this README file. Then commit the changes.
